# rux new

Create a new Rux package in a new directory.

```sh
rux new [name] [options]
```

`--bin`, `--lib` and `--source` select the [package type](/packaging/types) and are mutually exclusive;
without one, a `Program` is created. A package that will be published also needs a
[namespace](/packaging/namespaces), which `--namespace` writes into the manifest.

## Options

| Option             | Description                                              |
| ------------------ | -------------------------------------------------------- |
| `--bin`            | Create a `Program` package with an entry point (default) |
| `--lib`            | Create a `Library` package built as a shared library     |
| `--source`         | Create a `Source` package compiled into its dependents   |
| `--namespace <ns>` | Set the registry namespace required to publish           |
| `--path <dir>`     | Create the package in a specific directory               |

## Examples

```sh
# A runnable program
rux new Program
rux new Program --bin

# A library that will be published as Acme/Widget
rux new Widget --lib --namespace Acme
```

Creates such folders and files:

```
Program/
├── Bin/
│   ├── Debug/
│   └── Release/
├── Src/
│   └── Main.rux
├── Temp/
├── Rux.toml
└── .gitignore
```

A `Source` package links no artifact of its own, so it gets no `Bin/` or `Temp/` directories. See
[Directory Layout](/packaging/layout).
