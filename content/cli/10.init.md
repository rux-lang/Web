# rux init

Initialize a new package in the current directory (useful for existing code).

```sh
rux init [options]
```

If `Rux.toml` does not exist, it will be created. `--bin`, `--lib` and `--source` select the
[package type](/packaging/types) and are mutually exclusive; without one, a `Program` is created.

## Options

| Option             | Description                                                             |
| ------------------ | ----------------------------------------------------------------------- |
| `--bin`            | Create a `Program` package with an entry point (default)                |
| `--lib`            | Create a `Library` package built as a shared library                    |
| `--source`         | Create a `Source` package compiled into its dependents                  |
| `--namespace <ns>` | Set the [registry namespace](/packaging/namespaces) required to publish |

## Examples

```sh
# A runnable program
rux init --bin

# A library that will be published under a namespace
rux init --lib --namespace Acme
```
