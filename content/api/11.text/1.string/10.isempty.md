# `IsEmpty`

Reports whether the string holds no bytes.

**Package:** `Text`

## Signature

```rux
func IsEmpty(self) -> bool;
```

## Returns

`true` when the string holds no bytes, which is the case for [`New`](/api/text/string/new), for anything [`Free`](/api/text/string/free) has left behind, and for a transformation that had nothing to give back.

## Example

```rux
import Text::String;

func Main() -> int {
    String::New().IsEmpty(); // true

    var text = String::From("Rux");
    text.IsEmpty();          // false

    text.Free();
    text.IsEmpty();          // true -- Free leaves an empty string behind
    return 0;
}
```
