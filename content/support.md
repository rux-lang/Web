# Support Rux

Rux is free, open source, and developed independently. You can support it with a donation, with code and documentation, or simply by telling other developers about it.

## Donate

Donations fund the time that goes into the compiler, the standard library, the tooling, and the documentation. Pick the platform that suits you best — every contribution helps.

## Report an Issue

Different problems go to different places, so nothing gets lost — and so a vulnerability is never
disclosed in public before there is a fix.

::u-page-grid
:link-card{name="Report a Bug" handle="rux-lang/Rux/issues" description="Incorrect compiler, CLI, or package-manager behavior. The template asks for a minimal reproducer." icon="i-lucide-bug" color="text-rose-500" note="Public issue" to="https://github.com/rux-lang/Rux/issues/new?template=bug_report.yml"}
:link-card{name="Propose a Feature" handle="rux-lang/Rux/discussions" description="Language and tooling ideas start in Discussions, where they can be shaped before becoming an issue." icon="i-lucide-lightbulb" color="text-amber-500" note="Discussion" to="https://github.com/rux-lang/Rux/discussions"}
:link-card{name="Report a Vulnerability" handle="rux-lang.dev/security" description="Security problems are reported privately. Please do not open a public issue for them." icon="i-lucide-shield-alert" color="text-violet-500" note="Private report" to="/security"}
::

Usage questions are answered faster on [Discord](https://discord.com/invite/uvSHjtZSVG) than in the
issue tracker.
