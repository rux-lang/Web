# Numeric capabilities

The intrinsic interfaces a generic bound names to admit integer or floating-point arithmetic — [`Integer`](/docs/api/core/arithmetic#integer), [`SignedInteger`](/docs/api/core/arithmetic#signed-integer) and [`Float`](/docs/api/core/arithmetic#float) — and the limits of an integer type.

<h2 id="integer"><code>Integer</code></h2>

```rux
pub interface Integer {}
```

An integer of any width, signed or not. The compiler decides it from the type, so nothing implements it; it is
only a bound, and it implies [`Copyable`](/docs/api/core/copyable), since every integer is plain data.

[Source](https://github.com/rux-lang/Rux/blob/main/Packages/Core/Src/Arithmetic.rux#L21)

<h2 id="signed-integer"><code>SignedInteger</code></h2>

```rux
pub interface SignedInteger {}
```

A signed integer of any width. The compiler decides it from the type, and it implies [`Integer`](/docs/api/core/arithmetic#integer) and [`Copyable`](/docs/api/core/copyable).

[Source](https://github.com/rux-lang/Rux/blob/main/Packages/Core/Src/Arithmetic.rux#L25)

<h2 id="float"><code>Float</code></h2>

```rux
pub interface Float {}
```

A floating-point number of any width. The compiler decides it from the type, and it implies [`Copyable`](/docs/api/core/copyable).

[Source](https://github.com/rux-lang/Rux/blob/main/Packages/Core/Src/Arithmetic.rux#L29)

<h2 id="maximum-of"><code>MaximumOf&lt;T&gt;</code></h2>

```rux
pub func MaximumOf<T: Copyable>(sample: T) -> T
```

The largest value the integer type of `sample` can hold.
`sample` is read by value and only its type matters; its value is never used. Returns the maximum by copy.
Cannot fail. Runs in constant time and allocates nothing.

[Source](https://github.com/rux-lang/Rux/blob/main/Packages/Core/Src/Arithmetic.rux#L38)

<h2 id="minimum-of"><code>MinimumOf&lt;T&gt;</code></h2>

```rux
pub func MinimumOf<T: Copyable>(sample: T) -> T
```

The smallest value the integer type of `sample` can hold.
`sample` is read by value and only its type matters. Returns the minimum by copy: zero for an unsigned type, and
the most negative value for a signed one.
Cannot fail. Runs in constant time and allocates nothing.

[Source](https://github.com/rux-lang/Rux/blob/main/Packages/Core/Src/Arithmetic.rux#L55)
