# Integer arithmetic

Checked, wrapping and saturating arithmetic at every integer width, the limits of an integer type, and the [`uint64`](/docs/api/core/integers#uint64) intrinsics allocation sizes are computed with.

<h2 id="maximum-of"><code>MaximumOf&lt;T&gt;</code></h2>

```rux
pub func MaximumOf<T>(sample: T) -> T
```

The largest value the integer type of `sample` can hold.
`sample` is read by value and only its type matters; its value is never used. Returns the maximum by copy.
Cannot fail. Runs in constant time and allocates nothing.

<h2 id="add-checked"><code>AddChecked&lt;T&gt;</code></h2>

```rux
pub func AddChecked<T>(left: T, right: T, result: *var T) -> bool
```

Adds two integers and reports whether the true sum is representable.
`left` and `right` are read by value. `result` receives the sum the machine produced, which is the true sum when
this returns `false` and the wrapped one when it returns `true`; it is written in both cases, so a caller that
wants the wrapped answer does not have to compute it again. `result` must not be null.
Returns `true` when the sum overflowed. Never traps, so the caller decides what a sum too large to express means.
Runs in constant time and allocates nothing.

[Source](https://github.com/rux-lang/Rux/blob/main/Packages/Core/Src/Arithmetic.rux#L61)

<h2 id="mul-checked"><code>MulChecked&lt;T&gt;</code></h2>

```rux
pub func MulChecked<T>(left: T, right: T, result: *var T) -> bool
```

Multiplies two integers and reports whether the true product is representable.
`left` and `right` are read by value. `result` receives the product the machine produced, true or wrapped, and is
written in both cases. `result` must not be null.
Returns `true` when the product overflowed. This is the operation an allocation size is computed with: a wrapped
