# Characters

The character types [`char8`](/docs/api/core/characters#char8) to [`char64`](/docs/api/core/characters#char64), with their width and limit constants. The built-in `char` is [`char32`](/docs/api/core/characters#char32) and shares its constants. The widths `char128`, `char256` and `char512` are reserved and not implemented yet.
