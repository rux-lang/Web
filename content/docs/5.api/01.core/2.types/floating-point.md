# Floating-point types

The IEEE 754 types [`float32`](/docs/api/core/floating-point#float32) and [`float64`](/docs/api/core/floating-point#float64) and the [`float`](/docs/api/core/floating-point#float) alias, with their width, limit and special-value constants. The widths `float8`, `float16`, `float80`, `float128`, `float256` and `float512` are reserved and not implemented yet.
