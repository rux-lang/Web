# Interfaces

An interface declares a set of method signatures that a type must satisfy, enabling shared behavior across unrelated types. Each aspect has a dedicated chapter:

| Topic                                                  | Description                                 |
| ------------------------------------------------------ | ------------------------------------------- |
| [Declaration](/docs/lang/interfaces/declaration)       | Declaring the methods an interface requires |
| [Implementation](/docs/lang/interfaces/implementation) | Satisfying an interface with `extend`       |

## See Also

- [Methods](/docs/lang/structs/methods) — attaching behaviour to a type with `extend`
- [Structures](/docs/lang/structs/overview) — the types that most often implement interfaces
