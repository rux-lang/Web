# Functions

A function groups a sequence of statements under a name so it can be invoked repeatedly. Rux supports several kinds of functions, each covered in a dedicated chapter:

| Kind                                            | Description                                       |
| ----------------------------------------------- | ------------------------------------------------- |
| [Declaration](/docs/lang/functions/declaration) | Declaring functions, parameters, and return types |
| [Variadic](/docs/lang/functions/variadic)       | Functions that accept any number of arguments     |
| [Generic](/docs/lang/functions/generic)         | Functions parameterized over types                |
| [Assembler](/docs/lang/functions/assembler)     | Functions whose body is written in assembly       |
| [Main](/docs/lang/functions/main)               | The program entry point                           |
