# Foreign Function Interface

The foreign function interface (FFI) lets Rux call functions defined outside the language — typically in C / C++ libraries — and exchange data with them. Each part of the FFI has a dedicated chapter:

| Topic                                          | Description                                           |
| ---------------------------------------------- | ----------------------------------------------------- |
| [`extern` Declarations](/docs/lang/ffi/extern) | Declaring functions defined outside Rux               |
| [Linking Libraries](/docs/lang/ffi/import)     | Binding declarations to a native library with `#Link` |

Pointers are central to passing memory across the boundary — see [Pointers and `extern`](/docs/lang/pointers/extern).
