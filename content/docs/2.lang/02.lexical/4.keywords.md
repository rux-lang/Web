# Keywords

A keyword is a word the language reserves. Keywords are lower case and case-sensitive, and none of them can be used as an [identifier](/docs/lang/lexical/identifiers): `While` is an ordinary name, `while` is not.

## Reserved keywords

Rux reserves 44 words:

```text
as        break     catch     const     continue  defer     do        else
enum      extend    extern    fail      false     finally   for       func
if        import    in        interface intrinsic is        let       loop
match     module    move      none      null      pub       return    self
struct    throw     throws    true      try       type      union     unsafe
var       variant   when      while
```

| Keyword                                            | Introduces                                                                                     |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| [`as`](/docs/lang/expressions/casts)               | A conversion, `value as T`                                                                     |
| [`break`](/docs/lang/statements/break-continue)    | An exit from the nearest enclosing loop                                                        |
| [`catch`](/docs/lang/errors/handling)              | The arms that handle an error after `try`, `try x catch { … }` or `try { … } catch { … }`      |
| [`const`](/docs/lang/bindings/constants)           | A compile-time constant                                                                        |
| [`continue`](/docs/lang/statements/break-continue) | A jump to the next iteration of a loop                                                         |
| [`defer`](/docs/lang/ownership/defer)              | A statement run when the enclosing scope exits                                                 |
| [`do`](/docs/lang/statements/loops)                | A `do { … } while condition;` loop, which tests after the body                                 |
| [`else`](/docs/lang/statements/if)                 | The alternative of an `if`, statement or value                                                 |
| [`enum`](/docs/lang/enums/overview)                | An enumeration of named integer values                                                         |
| [`extend`](/docs/lang/structs/extensions)          | An extension block of methods, constructors and constants for a type                           |
| [`extern`](/docs/lang/ffi/overview)                | A declaration of a function or variable defined outside Rux                                    |
| `fail`                                             | Nothing: it is reserved, and `fail value;` is rejected in favour of `throw value;`             |
| [`false`](/docs/lang/types/booleans)               | The boolean value false                                                                        |
| `finally`                                          | Nothing: it is reserved, and cleanup on every exit uses `defer`                                |
| [`for`](/docs/lang/statements/loops)               | A loop over a range, slice, array or iterable                                                  |
| [`func`](/docs/lang/functions/declaration)         | A function, a method or a function type                                                        |
| [`if`](/docs/lang/statements/if)                   | A conditional statement, or an [`if` value](/docs/lang/expressions/conditional)                |
| [`import`](/docs/lang/modules/imports)             | Names brought into scope from a package or module                                              |
| [`in`](/docs/lang/statements/loops)                | The sequence of a `for` loop, `for item in items`                                              |
| [`interface`](/docs/lang/interfaces/overview)      | A set of methods a type can implement                                                          |
| [`intrinsic`](/docs/lang/comptime/intrinsics)      | A declaration the compiler implements: a function, constant or value                           |
| [`is`](/docs/lang/sums/type-tests)                 | A type or pattern test, `value is T` or `entry is .Some(v)`                                    |
| [`let`](/docs/lang/bindings/overview)              | An immutable binding                                                                           |
| [`loop`](/docs/lang/statements/loops)              | A loop with no condition                                                                       |
| [`match`](/docs/lang/patterns/match)               | A selection by pattern                                                                         |
| [`module`](/docs/lang/modules/overview)            | A named module block, `module A::B { … }`                                                      |
| [`move`](/docs/lang/ownership/copy-and-move)       | A transfer of ownership, `move value`, which consumes the source                               |
| [`none`](/docs/lang/optionals/overview)            | The absent value of an optional                                                                |
| [`null`](/docs/lang/pointers/overview)             | The null pointer                                                                               |
| [`pub`](/docs/lang/modules/visibility)             | Visibility outside the declaring package                                                       |
| [`return`](/docs/lang/statements/return)           | A return from the enclosing function                                                           |
| [`self`](/docs/lang/structs/methods)               | The receiver parameter of a method                                                             |
| [`struct`](/docs/lang/structs/overview)            | A structure type                                                                               |
| [`throw`](/docs/lang/errors/overview)              | A statement that throws an error, `throw value;`                                               |
| [`throws`](/docs/lang/errors/overview)             | The error a function can throw, `-> T throws E`                                                |
| [`true`](/docs/lang/types/booleans)                | The boolean value true                                                                         |
| [`try`](/docs/lang/errors/handling)                | A mark on a call that can throw: `try`, `try?`, `try … catch`, or a `try` block                |
| [`type`](/docs/lang/types/aliases)                 | A type alias, `type Name = T;`                                                                 |
| [`union`](/docs/lang/unions/overview)              | A union type, whose fields share storage                                                       |
| [`unsafe`](/docs/lang/pointers/overview)           | An `unsafe { … }` block or `unsafe func`, where raw-pointer and foreign operations are allowed |
| [`var`](/docs/lang/bindings/overview)              | A mutable binding, and writability in `&var T`, `*var T` and `var T[..]`                       |
| [`variant`](/docs/lang/variants/overview)          | A tagged type whose cases may carry payloads                                                   |
| [`when`](/docs/lang/comptime/conditional)          | A compile-time conditional                                                                     |
| [`while`](/docs/lang/statements/loops)             | A loop that tests a condition before each iteration                                            |

`true` and `false` are lexed as boolean [literals](/docs/lang/lexical/literals#boolean-literals), and are reserved like the other 42.

## Contextual words

These words are ordinary identifiers except in one position, where they take a fixed meaning. Outside that position they can name things, although using them as names makes code harder to read.

| Word                | Meaning, and where                                                                                                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `asm`               | Directly before `func`: a function whose body is [assembly](/docs/lang/ffi/assembly)                                                                                                |
| `sizeof`, `alignof` | In an expression: the size or alignment of a type, `sizeof(T)`. An expression cannot read a binding with either name.                                                               |
| `thread`            | Directly before a module-level `var`: a [thread-local variable](/docs/lang/bindings/module-variables#thread-local-variables), `thread var Depth: int32 = 0;`                        |
| `Self`              | In an `extend` block: the extended type with its type arguments, as in `-> Self`; in an interface: the implementing type                                                            |
| `_`                 | In a binding or pattern: discards the value instead of naming it                                                                                                                    |
| `Some`              | After a leading `.`: the native constructor and pattern `.Some(v)` of [optionals](/docs/lang/optionals/overview), unless the expected type is a variant that declares a `Some` case |

Primitive type names — `int`, `uint8`, `float64`, `bool`, `char` and the rest — are not keywords either. They are predefined type names, listed in the [Primitive Types](/docs/lang/appendix/primitives) appendix, and so is `opaque`, the unknown pointee of an untyped pointer `*opaque`.

Some words that other languages reserve mean nothing special in Rux: `mut`, `use`, `impl` and `fn` are ordinary identifiers.
