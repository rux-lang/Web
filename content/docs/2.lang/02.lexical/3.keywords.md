# Keywords

The following words are reserved and may not be used as [identifiers](/docs/lang/lexical/identifiers). Keywords are case-sensitive and are listed below in ascending order, each linked to the chapter that describes it in full.

Built-in type names (`int`, `bool`, `char32`, …) are **not** keywords — they are predefined identifiers in the type namespace. For a consolidated list of them, see the [Primitive Type Reference](/docs/lang/appendix/primitives).

| Keyword                                            | Role                                                           |
| -------------------------------------------------- | -------------------------------------------------------------- |
| [`as`](/docs/lang/operations/type-cast)            | Converts a value from one type to another (cast)               |
| [`asm`](/docs/lang/functions/assembler)            | Marks a function whose body is written in assembly             |
| [`break`](/docs/lang/statements/break-continue)    | Exits the nearest enclosing loop                               |
| [`const`](/docs/lang/constants/overview)           | Declares a compile-time constant                               |
| [`continue`](/docs/lang/statements/break-continue) | Skips to the next iteration of a loop                          |
| [`else`](/docs/lang/statements/if)                 | Introduces the alternative branch of an `if`                   |
| [`enum`](/docs/lang/enums/overview)                | Declares an enumeration type                                   |
| [`extend`](/docs/lang/interfaces/implementation)   | Attaches methods to a type, optionally implementing interfaces |
| [`extern`](/docs/lang/ffi/extern)                  | Declares a function or symbol defined outside Rux              |
| [`false`](/docs/lang/boolean/bool)                 | The false boolean value                                        |
| [`for`](/docs/lang/statements/for)                 | Iterates over the elements of a sequence                       |
| [`func`](/docs/lang/functions/declaration)         | Declares a function                                            |
| [`if`](/docs/lang/statements/if)                   | Begins a conditional branch                                    |
| [`import`](/docs/lang/modules/import)              | Brings names from a module into scope                          |
| [`in`](/docs/lang/statements/for)                  | Separates the loop variable from the sequence in a `for` loop  |
| [`interface`](/docs/lang/interfaces/declaration)   | Declares an interface                                          |
| [`is`](/docs/lang/operations/type-test)            | Tests whether a value has a given type                         |
| [`let`](/docs/lang/variables/let)                  | Declares an immutable variable                                 |
| [`loop`](/docs/lang/statements/loop)               | Begins an unconditional loop                                   |
| [`match`](/docs/lang/statements/match)             | Selects a branch by pattern matching                           |
| [`module`](/docs/lang/modules/declaration)         | Declares a module (namespace)                                  |
| [`null`](/docs/lang/pointers/null)                 | The null pointer value                                         |
| [`pub`](/docs/lang/modules/visibility)             | Makes an item visible outside its module                       |
| [`return`](/docs/lang/functions/declaration)       | Returns a value from a function                                |
| [`self`](/docs/lang/interfaces/implementation)     | The receiver parameter of a method                             |
| [`struct`](/docs/lang/structs/overview)            | Declares a structure type                                      |
| [`true`](/docs/lang/boolean/bool)                  | The true boolean value                                         |
| [`type`](/docs/lang/aliases/overview)              | Declares a type alias                                          |
| [`union`](/docs/lang/unions/overview)              | Declares a union type                                          |
| [`var`](/docs/lang/variables/var)                  | Declares a mutable variable                                    |
| [`while`](/docs/lang/statements/while)             | Loops while a condition holds                                  |
