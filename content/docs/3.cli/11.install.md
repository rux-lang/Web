# rux install

Download and install packages into the cache.

```sh
rux install
rux install [package]
rux install [package]@[version]
rux install --target <triple>
```

Without arguments, installs all dependencies listed in `Rux.toml`. With a package name, installs only that specific package and its transitive dependencies.

Resolution uses the host target by default. `--target <triple>` selects another supported target and filters root and transitive dependencies by their `TargetOS` allow-lists. An explicitly named package is still installed even when the root manifest conditions exclude it; the selected target filters that package's transitive dependencies.

## Options

| Option              | Description                                  |
| ------------------- | -------------------------------------------- |
| `--target <triple>` | Resolve dependencies for the selected target |

Packages are stored locally at:

- **Windows** — `%LOCALAPPDATA%\Rux\Packages`
- **Linux / macOS** — `~/.rux/packages`

## Examples

```sh
# Install all packages listed in Rux.toml
rux install

# Install a specific package
rux install Json

# Install a specific version
rux install Math@0.3.1

# Resolve a Windows dependency graph from any host
rux install --target windows-x86_64
```
