# rux update

Update packages.

```sh
rux update
rux update --global
rux update --target <triple>
```

Without flags, checks all registry dependencies listed in `Rux.toml` and pulls the latest changes for each one. With `--global`, updates all packages in the cache.

Missing packages are cloned from the registry. Transitive dependencies are resolved and updated automatically.

Resolution uses the host target by default. `--target <triple>` resolves the manifest dependency graph for another supported target and filters root and transitive dependencies by their `TargetOS` allow-lists. Package archives are target-independent, so the selected target does not need to match the host running the command.

Packages are stored locally at:

- **Windows** — `%LOCALAPPDATA%\Rux\Packages`
- **Linux / macOS** — `~/.rux/packages`

## Options

| Option              | Description                                  |
| ------------------- | -------------------------------------------- |
| `--global`          | Update all packages in the cache             |
| `--target <triple>` | Resolve dependencies for the selected target |

## Examples

```sh
# Update packages listed in Rux.toml
rux update

# Update all packages in the cache
rux update --global

# Update the Linux dependency graph from any host
rux update --target linux-x86_64
```
