# rux pack

Build the `.ruxpkg` archive that [`rux publish`](/docs/cli/publish) uploads.

```sh
rux pack [options]
```

The archive contains `Rux.toml` at its root, every file below `Src/`, and the files named by the
manifest's `ReadmeFile` and `LicenseFile`. Entries are sorted and carry a fixed timestamp, so packing the
same tree twice produces byte-identical output.

Without `--output`, the archive is written to the package's build output directory as
`<Name>-<Version>.ruxpkg`.

`rux pack` applies the same [publication rules](/docs/packaging/manifest#validation-profiles) as
`rux publish`: the manifest needs a `Namespace` and a `MinRux`, cannot describe a workspace, and cannot
carry path dependencies. Use it to inspect exactly what a release would contain before uploading one.

## Options

| Option            | Description                          |
| ----------------- | ------------------------------------ |
| `--output <path>` | Write the archive to a specific path |

## Examples

```sh
# Write <Name>-<Version>.ruxpkg to the build output directory
rux pack

# Write it somewhere specific
rux pack --output Dist/Math.ruxpkg
```

A `.ruxpkg` is an ordinary ZIP archive, so any ZIP tool can list its contents.
