# rux check

Parse and analyze the workspace for syntactic and semantic problems without emitting any binaries.

```sh
rux check [options]
```

Checking is faster than a build because nothing is code-generated or linked. It accepts every
[package type](/docs/packaging/types), including `Source` packages, which [`rux build`](/docs/cli/build) rejects
as a top-level target. Run from a workspace root, it checks every member package.

## Options

| Option                    | Description                                 |
| ------------------------- | ------------------------------------------- |
| `--define <name[=value]>` | Set or override a config compile-time value |
| `--json`                  | Output diagnostics in JSON format           |
| `--target <triple>`       | Check for a specific target platform        |

## Examples

```sh
# Check the current package or workspace
rux check

# Machine-readable diagnostics for an editor or CI job
rux check --json

# Check the code as it would compile for another platform
rux check --target windows-x86_64
```
