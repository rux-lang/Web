# rux lint

Run source-level diagnostics without emitting build artifacts.

```sh
rux lint [options]
```

Linting reports style and correctness warnings — naming conventions, unused items, and suspicious
constructs — over the current package or every member of a workspace. Individual rules can be silenced
at a declaration with the [`#Allow`](/docs/lang/attributes/allow) attribute.

Use [`rux check`](/docs/cli/check) for complete semantic validation; `lint` is the lighter, style-oriented
pass.

## Examples

```sh
# Lint the current package or workspace
rux lint

# Report each file as it is processed
rux lint --verbose
```
