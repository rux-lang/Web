# rux info

Show metadata for an installed Rux package.

```sh
rux info
rux info [package]
```

Without a package name, reports the current package from its `Rux.toml` — namespace, name, version,
[type](/docs/packaging/types), description, authors, and keywords. With a name, reports that package from the
local [package store](/docs/packaging/dependencies#package-storage).

## Options

| Option   | Description                            |
| -------- | -------------------------------------- |
| `--json` | Output package metadata in JSON format |

## Examples

```sh
# The current package
rux info

# An installed package
rux info Rux

# Machine-readable output
rux info Windows --json
```
