# rux logout

Remove the token [`rux login`](/docs/cli/login) stored for a registry.

```sh
rux logout
rux logout --registry <url>
```

Only the selected registry's entry is removed; tokens stored for other registries are kept. Logging out
of a registry you never logged in to is not an error. When the last entry goes, the credentials file is
removed with it.

`RUX_TOKEN` is an environment variable, not a stored token, and is unaffected.

Logging out does not revoke the token — it only forgets it locally. To make a token stop working
everywhere, revoke it from [Dashboard → Tokens](/packages/-/dashboard/tokens).

## Options

| Option             | Description                                   |
| ------------------ | --------------------------------------------- |
| `--registry <url>` | Registry API base URL to forget the token for |

## Environment

| Variable           | Description                                  |
| ------------------ | -------------------------------------------- |
| `RUX_REGISTRY_URL` | Default registry, overridden by `--registry` |

## Examples

```sh
# Forget the token for the official registry
rux logout

# Forget the token for a local registry
rux logout --registry http://localhost:8080
```

```
  Logged out of https://api.rux-lang.dev
```
