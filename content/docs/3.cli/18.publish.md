# rux publish

Upload the package archive to a Rux package registry.

```sh
rux publish [options]
```

Publishing packs the current package with [`rux pack`](/docs/cli/pack) and uploads the archive together with
the exact `Rux.toml` bytes embedded in it. A published version is **immutable** — see
[Publishing](/docs/packaging/publishing) for the full walkthrough.

Publication requires `[Package].Namespace` and `[Manifest].MinRux`, and rejects workspace manifests and
path dependencies. All of that is checked locally, before anything is uploaded.

`rux publish` does not build or check the package first. Run [`rux check`](/docs/cli/check) beforehand.

## Options

| Option             | Description                                      |
| ------------------ | ------------------------------------------------ |
| `--registry <url>` | Registry API base URL to publish to              |
| `--dry-run`        | Validate and build the archive without uploading |

## Credentials

Publishing needs a token carrying the `publish` scope, taken from the first of these that applies:

1. the `RUX_TOKEN` environment variable;
2. the token [`rux login`](/docs/cli/login) stored for the registry being published to.

The environment wins, so a CI job is never shadowed by a file left behind on a self-hosted runner.
`--dry-run` needs no credential at all.

There is deliberately no `--token` flag: a credential passed as an argument ends up in shell history and
in the process list. See [API Tokens](/docs/packaging/tokens).

## Environment

| Variable           | Description                                                                   |
| ------------------ | ----------------------------------------------------------------------------- |
| `RUX_TOKEN`        | Bearer credential; overrides a token stored by [`rux login`](/docs/cli/login) |
| `RUX_REGISTRY_URL` | Default registry, overridden by `--registry`                                  |

## Examples

```sh
# Validate and pack without uploading — no token needed
rux publish --dry-run

# Publish to the official registry
rux publish

# Publish to a local registry
rux publish --registry http://localhost:8080
```
