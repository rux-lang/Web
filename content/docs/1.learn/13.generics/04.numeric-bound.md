## The program

The whole lesson is one package in the [Examples repository](https://github.com/rux-lang/Examples/tree/main/Generics/NumericBound). Its comments explain every step.

<!-- sync:program:start -->

```rux [Src/Main.rux]
// GenericBound bounded `T` by an interface you wrote, so the body could call its methods. Numbers
// need something an interface cannot list: the operators. A body that adds two `T`s needs `+` on
// every type it might be given, and `Core::Arithmetic` has three bounds that promise exactly that:
//
//     Integer         an integer of any width, signed or not
//     SignedInteger   a signed integer, which is an Integer too
//     Float           a floating-point number of any width
//
// Under one of them the body may use the operators of those numbers on a `T`: `+`, `-`, `*`, `/`,
// `<` and the rest. A literal becomes a `T` with `as`, as in `0 as T`. And because every number
// is plain data, each bound makes `T` copyable, so a `T` can be used as often as the body likes.
//
// Nothing implements these interfaces. The compiler decides them from the type, and they exist
// only as bounds. `Copyable`, from `Core::Ownership`, is the same kind of interface: `T: Copyable`
// admits any plain data and lets a `T` be copied, but it adds no operators, and no value ever has
// the type `Copyable`.
import Core::Arithmetic::{ Float, Integer, SignedInteger };
import Io::PrintLine;

// One function for every integer type. `T` is read out of the slice it is given.
func Sum<T: Integer>(values: T[..]) -> T {
    var total = 0 as T;
    for value in values {
        total += value;
    }
    return total;
}

// `high` starts as a copy of `low`. Without a bound a `T` might own something, so
// `var high = low;` would give `low` away and the loop could not read it; under `Integer` the
// value is copied and both stay usable.
func Range<T: Integer>(values: T[..]) -> (T, T) {
    var low = values[0];
    var high = low;
    for value in values {
        if value < low {
            low = value;
        }
        if value > high {
            high = value;
        }
    }
    return (low, high);
}

// Negating needs a sign, so this bound is the narrower `SignedInteger`.
func Magnitude<T: SignedInteger>(value: T) -> T {
    if value < 0 as T {
        return -value;
    }
    return value;
}

// Division that keeps the fraction, so a floating-point bound.
func Average<T: Float>(values: T[..]) -> T {
    var total = 0.0 as T;
    for value in values {
        total += value;
    }
    return total / (values.length as T);
}

func Main() -> int {
    let scores: int32[4] = [12, 7, 30, 1];
    let sizes: uint64[3] = [4096, 512, 1024];
    let temperatures: float64[3] = [18.5, 21.0, 19.0];

    PrintLine("sum of scores    {}", Sum(scores));
    PrintLine("sum of sizes     {}", Sum(sizes));
    let (low, high) = Range(scores);
    PrintLine("range of scores  {} to {}", low, high);
    PrintLine("magnitude of -7  {}", Magnitude<int64>(-7));
    PrintLine("average          {}", Average(temperatures));

    // The bound is checked at the call. `Sum(temperatures)` is refused there, before the body is
    // looked at:
    //
    // error: type argument 'float64' does not satisfy interface bound 'Integer' on type
    //        parameter 'T'
    //   note: 'float64' is not an integer
    //   note: type parameter 'T' of function 'Sum' is bound by 'Integer'
    //   help: pass an integer type, such as 'int' or 'uint'
    //
    // `Magnitude(sizes[0])` is refused the same way, with the note "'uint64' is not a signed
    // integer".
    return 0;
}
```
