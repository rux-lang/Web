# If let

::note
<!-- sync:needs:start -->

**You'll need**: [Presence](/docs/learn/presence), [Variant match](/docs/learn/variant-match), [Mutating method](/docs/learn/mutating-method), [While](/docs/learn/while)
<!-- sync:needs:end -->

::

A `match` needs an arm for every case. When only the present case has any work to do, that `none` arm is ceremony, and an `if` says it more directly. `if let` puts a pattern right into the condition: the body runs when the pattern matches, with its names bound to what it found.

## if let

The lesson's `Report` prints a player's score, or says the number is not on the team:

```rux
func Report(players: Player[..], number: int) {
    if let score? = ScoreOf(players, number) {
        PrintLine("#{} scored {}", number, score);
    } else {
        PrintLine("#{} is not on the team", number);
    }
}
```

`score?` is the same pattern a [match arm](/docs/learn/presence) takes — "a present value, called `score`". When `ScoreOf` finds the player, the pattern matches, `score` is bound to the `int` inside and the body runs. When it returns `none`, the pattern does not match and the `else` block runs instead.

```mermaid
flowchart LR
    s["`ScoreOf(players, number)`"] --> q{"`score?`<br/>matches?"}
    q -- "present" --> b["body<br/>`score` is the `int`"]
    q -- "`none`" --> e["`else`<br/>no `score` here"]
```

`score` exists only in the body. It is not in the `else` block, where nothing was found, and it is not after the `if` either. The `else` may be left out when absence needs nothing done.

| You want…                             | Write                                                     |
| ------------------------------------- | --------------------------------------------------------- |
| different code for each case          | `match` with `score? =>` and `none =>`                    |
| code only when the value is there     | `if let score? = …`                                       |
| only whether it is there, as a `bool` | `… != none` or `… == none`                                |
| to keep going with a stand-in         | `… ?? fallback` — the [next lesson](/docs/learn/coalesce) |

## More conditions with &&

The binding can be followed by more conditions, joined with `&&`. They are checked only once the pattern has matched, so they can already use the name it bound:

```rux
for number in [ 7, 10 ] {
    if let score? = ScoreOf(players, number) && score >= 20 {
        PrintLine("#{} is the top scorer", number);
    }
}
```

Player 7 is present but scored only 12, so the body runs for player 10 alone. The binding always comes first: a condition before it, or a `||` anywhere, would leave `score` in scope on a path where nothing was bound.

## if var

`if let` binds a name that cannot change. `if var` binds one that can:

```rux
if var score? = ScoreOf(players, 4) {
    score += 3;
    PrintLine("#4 after a hat-trick: {}", score);
}
```

`score` is a copy of the `int` inside the optional, so adding to it changes nothing in `players`.

## while let

`while let` is the loop form. It tries the pattern before every pass, binds the name afresh each time, and stops at the first value that does not match. The lesson's `Replay` hands out the events of a game one at a time from its `Next` method, then `none` once they are all told:

```rux
while let event? = replay.Next() {
    // A case pattern binds what the case carries, just as in a match arm.
    if let .Goal(number) = event {
        PrintLine("  goal by #{}", number);
    } else if let .Foul(number) = event {
        PrintLine("  foul by #{}", number);
    } else if event is .Pause {
        PrintLine("  the game is paused");
    }
}
```

```mermaid
flowchart TD
    n["`replay.Next()`"] --> q{"`event?`<br/>matches?"}
    q -- "present" --> b["body, with `event`"]
    b --> n
    q -- "`none`" --> d["after the loop"]
```

`Next` is a [mutating method](/docs/learn/mutating-method) — it moves `next` along — so `replay` is a `var`.

## Any pattern

The pattern after `let` is any pattern a match arm takes, not only `value?`. Inside the loop, `if let .Goal(number) = event` uses a case pattern, which binds what the case carries just as in a [variant match](/docs/learn/variant-match), and `else if let` tries the next pattern when the first did not match.

The last test is an `is`. `is` only tests: it answers with a `bool` and never binds a name, which is all `.Pause` needs, since it carries nothing. To test a case that does carry something, write `_` where a name would go, `event is .Goal(_)`; to use what it carries, write `if let`.

## The program

The whole lesson is one package in the [Examples repository](https://github.com/rux-lang/Examples/tree/main/Optionals/IfLet). Its comments explain every step.

<!-- sync:program:start -->

```rux [Src/Main.rux]
// A `match` needs an arm for every case. When only the present case has any work to do, an `if`
// says it more directly. `if let` puts a pattern into the condition:
//
//     if let score? = ScoreOf(players, number) { ... } else { ... }
//
// The body runs when the pattern matches, with `score` bound to the `int` inside. `else` runs
// when it does not. `score` exists only in the body: not in `else`, and not after the `if`.
//
// The pattern after `let` is any pattern a match arm takes, and more conditions may follow it
// with `&&`. `while let` is the loop form: it tries the pattern before every pass and stops at the
// first value that does not match.
import Io::PrintLine;

struct Player {
    number: int;
    score: int;
}

variant Event {
    Goal(int),
    Foul(int),
    Pause
}

// Hands out the events of a game one at a time, then `none` once they are all told.
struct Replay {
    events: Event[4];
    next: uint;
}

extend Replay {
    func Next(&var self) -> Event? {
        if self.next == 4 {
            return none;
        }
        self.next += 1;
        return self.events[self.next - 1];
    }
}

func ScoreOf(players: Player[..], number: int) -> int? {
    for player in players {
        if player.number == number {
            return player.score;
        }
    }
    return none;
}

func Report(players: Player[..], number: int) {
    if let score? = ScoreOf(players, number) {
        PrintLine("#{} scored {}", number, score);
    } else {
        PrintLine("#{} is not on the team", number);
    }
}

func Main() -> int {
    let players = [
        Player { number: 4, score: 0 },
        Player { number: 7, score: 12 },
        Player { number: 10, score: 25 }
    ];

    Report(players, 7);
    Report(players, 9);

    // The binding comes first, and the conditions after `&&` can already use it.
    for number in [ 7, 10 ] {
        if let score? = ScoreOf(players, number) && score >= 20 {
            PrintLine("#{} is the top scorer", number);
        }
    }

    // `if var` binds a name that may change. It holds a copy, so `players` is not touched.
    if var score? = ScoreOf(players, 4) {
        score += 3;
        PrintLine("#4 after a hat-trick: {}", score);
    }

    // Each pass calls `Next` again and binds `event` afresh; the first `none` ends the loop.
    var replay = Replay {
        events: [ Event::Goal(7), Event::Foul(4), Event::Pause, Event::Goal(10) ],
        next: 0
    };
    PrintLine("replay:");
    while let event? = replay.Next() {
        // A case pattern binds what the case carries, just as in a match arm.
        if let .Goal(number) = event {
            PrintLine("  goal by #{}", number);
        } else if let .Foul(number) = event {
            PrintLine("  foul by #{}", number);
        } else if event is .Pause {
            PrintLine("  the game is paused");
        }
    }

    // `is` only tests. It answers with a `bool` and never binds a name, so
    // `event is .Goal(number)` is refused with "'is' tests and does not bind 'number'".
    // Write `_` where a name would go to test, or `if let` to bind.
    return 0;
}
```

## Common mistakes

::mistake
**Leaving out the `?`.**\
`if let score = ScoreOf(players, number)` binds nothing useful — `score` would be the whole optional — and is refused:

```text
error: 'if let' binds the value of an optional, and the pattern has no '?'
help: add '?' after the name, as in 'if let name? = ...'
```

::

::mistake
**Using the name outside the body.**\
`score` is bound only where the pattern matched. Using it in the `else` block, or after the `if`, fails with:

```text
error: name 'score' is not defined in this scope
```

::

::mistake
**Binding with `is`.**\
`if event is .Goal(number)` looks like it should bind `number`, but `is` only tests:

```text
error: 'is' tests and does not bind 'number'
help: bind with 'if let', as in 'if let .Case(name) = subject { ... }', or write '_' to test only
```

::

::mistake
**A binding after `||`.**\
`if let score? = ScoreOf(players, number) || number > 3` would reach the body with no `score` when only the right side holds:

```text
error: a binding does not combine with '||', because its names would be in scope where nothing was bound
help: put the binding first and join further conditions with '&&'
```

::

::mistake
**Changing a name bound with `let`.**\
`score += 3;` inside an `if let` body fails with:

```text
error: cannot modify immutable variable 'score'
help: declare 'score' with 'var' to make it mutable
```

Write `if var` to bind a name that may change.
::

## Try it yourself

1. Leave out the `else` in `Report` and call it for player 9. What is printed?
2. Change the top-scorer test to `score >= 10`. Which players are printed now?
3. Add a fifth event, `Event::Goal(4)`, to the replay. What else has to change for `while let` to tell it?
4. Replace `else if event is .Pause` with a plain `else`. Does the output change, and why?
