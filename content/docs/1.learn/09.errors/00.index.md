# Part 9: Errors

Operations that can fail: `T ! E`.

## Lessons

|      | Lesson                                           | What you will learn                                                                    |
| ---- | ------------------------------------------------ | -------------------------------------------------------------------------------------- |
| 9.1  | [Fallible](/docs/learn/fallible)                 | return either a value or an error with `T ! E`                                         |
| 9.2  | [Fail](/docs/learn/fail)                         | report a failure with `fail`                                                           |
| 9.3  | [Unit fallible](/docs/learn/unit-fallible)       | a function that returns nothing but can still fail: `! E`                              |
| 9.4  | [Outcome](/docs/learn/outcome)                   | match a result as `.Success` or `.Failure`                                             |
| 9.5  | [Discard](/docs/learn/discard)                   | why the compiler refuses to let a result be ignored, and how to discard one on purpose |
| 9.6  | [Catch](/docs/learn/catch)                       | handle the ways an operation can fail with `catch`                                     |
| 9.7  | [Catch fallback](/docs/learn/catch-fallback)     | turn any failure into a default value with `catch { else => ... }`                     |
| 9.8  | [Propagate](/docs/learn/propagate)               | hand a failure straight to the caller with `?` instead of matching it                  |
| 9.9  | [Error variant](/docs/learn/error-variant)       | describe the ways an operation can fail with a variant                                 |
| 9.10 | [Error mapping](/docs/learn/error-mapping)       | add context to an error as it passes through with `? else (e => ...)`                  |
| 9.11 | [Error sum](/docs/learn/error-sum)               | fail in more than one way with an error sum `A \| B`                                   |
| 9.12 | [Fallible main](/docs/learn/fallible-main)       | let `Main` itself fail, and see the exit status                                        |
| 9.13 | [Absence to error](/docs/learn/absence-to-error) | turn a missing value into a failure with `?? fail`                                     |
| 9.14 | [Nested fallible](/docs/learn/nested-fallible)   | results inside results: `T? ! E` and `(T ! E1) ! E2`                                   |
| 9.15 | [Panic](/docs/learn/panic)                       | stop the program when something impossible happens                                     |
| 9.16 | [Assert](/docs/learn/assert)                     | check an assumption while the program runs                                             |
