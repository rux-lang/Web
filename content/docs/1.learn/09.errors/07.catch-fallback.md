# Catch fallback

::note
<!-- sync:needs:start -->

**You'll need**: [Catch](/docs/learn/catch), [Discard](/docs/learn/discard), [Coalesce](/docs/learn/coalesce)
<!-- sync:needs:end -->

::

Often the reason for a failure does not matter, only that there is a value to carry on with. `call !! fallback` says exactly that: the success if there is one, otherwise the fallback. Every error is replaced alike, so nothing needs listing.

## One fallback for every error

A settings form where every field is one typed digit, each with a sensible default:

```rux
let volume = ReadDigit('7') !! 5;
let brightness = ReadDigit('x') catch { _ => 8 };
let contrast = (ReadDigit(' ') !! none) ?? 5;
```

`'7'` reads fine, so `volume` is 7. `'x'` is not a digit and `' '` is blank — two different errors, and both get the field's default. The fallback must have the success type, an `int` here.

The three lines are three spellings of one idea. `!! 5` is the short one. `catch { _ => 8 }` is a [catch](/docs/learn/catch) whose single `_` arm takes every error. And `(… !! none) ?? 5` does it in two steps: `!! none` turns the error into absence, as in [Discard](/docs/learn/discard), and `??` supplies the default.

## The twin of ??

If you have done [Coalesce](/docs/learn/coalesce), the shape is familiar. `call !! fallback` is the error twin of `option ?? fallback`:

| You have           | Value or default               | The fallback runs |
| ------------------ | ------------------------------ | ----------------- |
| an optional `T?`   | `option ?? fallback`           | only when absent  |
| a fallible `T ! E` | `call !! fallback`             | only on an error  |
| a fallible `T ! E` | `call catch { _ => fallback }` | only on an error  |
| a fallible `T ! E` | `(call !! none) ?? fallback`   | only on an error  |

Like `??`, the fallback is worked out only when it is needed. A fallback that calls a function which prints something prints nothing at all when the read succeeds.

Why not just `??` on the call itself? Because a fallible is not an optional. `??` tests for absence, and using it on a fallible would throw the error away without the code saying so — so it is refused. `!! none` is the step that turns the error into absence on purpose.

## Parentheses around an operand

`!!` takes everything to its left, like `??`, so a `!!` that is one operand of a larger expression sits in parentheses. Adding up a code, where a digit that cannot be read counts as nothing:

```rux
let total = (ReadDigit('4') !! 0) + (ReadDigit('?') !! 0) + (ReadDigit('9') !! 0);
```

Each `!!` belongs to the `ReadDigit` inside its own parentheses, so the sum is 4 + 0 + 9 = 13. Without them, `ReadDigit('4') !! 0 + ReadDigit('?')` would read `0 + ReadDigit('?')` as the fallback. `!!` and `??` never share an expression without parentheses either, which is why `contrast` is written `(ReadDigit(' ') !! none) ?? 5`.

## The price

The convenience has a price: the error is thrown away unseen. `'x'` and `' '` both became defaults, and nothing in the program can tell which went wrong or why. When the reason should change what happens next, give `catch` one arm per case instead, as [Catch](/docs/learn/catch) does.

## The program

The whole lesson is one package in the [Examples repository](https://github.com/rux-lang/Examples/tree/main/Errors/CatchFallback). Its comments explain every step.

<!-- sync:program:start -->

```rux [Src/Main.rux]
// Often the reason for a failure does not matter, only that there is a value to carry on with.
// `call !! fallback` says exactly that: the success if there is one, otherwise the fallback. Every
// error is replaced alike, so nothing needs listing.
//
// It is the error twin of `option ?? fallback`, and it is shorthand for a `catch` whose single
// `_` arm takes every error: `call catch { _ => fallback }`. `(call !! none) ?? fallback` says the
// same thing in two steps: `!! none` turns the error into absence, and `??` supplies the default.
// Every way, the fallback is only worked out when it is needed, and it must have the success type
// — an `int` here.
//
// `!!` takes everything to its left, like `??`, so a `!!` that is one operand of a larger
// expression sits in parentheses.
import Io::PrintLine;

variant DigitError {
    Blank,
    NotADigit(char)
}

func ReadDigit(c: char) -> int ! DigitError {
    if c == ' ' {
        throw DigitError::Blank;
    }
    if c < '0' || c > '9' {
        throw DigitError::NotADigit(c);
    }
    return (c as int) - ('0' as int);
}

func Main() -> int {
    // A settings form where every field is one typed digit, each with a sensible default.
    let volume = ReadDigit('7') !! 5;
    let brightness = ReadDigit('x') catch { _ => 8 };
    let contrast = (ReadDigit(' ') !! none) ?? 5;
    PrintLine("volume {}, brightness {}, contrast {}", volume, brightness, contrast);

    // Adding up a code, where a digit that cannot be read counts as nothing. Without the
    // parentheses, `ReadDigit('4') !! 0 + ReadDigit('?')` would read `0 + ReadDigit('?')` as the
    // fallback.
    let total = (ReadDigit('4') !! 0) + (ReadDigit('?') !! 0) + (ReadDigit('9') !! 0);
    PrintLine("sum of 4?9 is {}", total);

    // The convenience has a price: the error is thrown away unseen. When the reason should
    // change what happens next, give `catch` one arm per case instead.
    return 0;
}
```

## Common mistakes

::mistake
**Using ?? on the call.**\
`ReadDigit('7') ?? 5` is refused:

```text
error: operator '??' cannot take 'int ! DigitError'
note: coalescing tests one optional level and would silently discard an error
```

The call gives a fallible, not an optional. Write `ReadDigit('7') !! 5`.
::

::mistake
**A `!!` inside a sum without parentheses.**\
`let total = ReadDigit('4') !! 0 + ReadDigit('?') !! 0;` fails twice:

```text
error: operator '+' cannot combine left operand 'int' with right operand 'int ! DigitError'
error: '!!' replaces an error, and 'int' has none
```

The first `!!` takes `0 + ReadDigit('?')` as its fallback, where the `+` meets a fallible, and the second `!!` lands on a plain `int`. Put each handled call in parentheses, as `total` does.
::

::mistake
**Mixing `!!` and `??` without parentheses.**\
`ReadDigit(' ') !! none ?? 5` is an error:

```text
error: '!!' and '??' are mixed without parentheses
help: group one of them, as in '(x !! none) ?? fallback'
```

::

## Try it yourself

1. Add up the digits `'7'`, `'x'` and `'7'` with a fallback of 0, then with a fallback of 5. Predict both sums.
2. Write `func Default() -> int` that prints `"(using the default)"` and returns 5, and use it as the fallback for `volume`. When does the line appear? Then try it on `ReadDigit('x')`.
3. Rewrite `brightness` with one arm per case — `Blank` gives 8, `NotADigit(_)` gives 0.
