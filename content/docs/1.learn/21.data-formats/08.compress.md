# Compress

::note

::

A web server's access log says the same few things over and over: the same paths, the same statuses, the same words. **Compression** finds what repeats and writes each repeat as a short reference back to an earlier copy, so a log, a JSON document or a page of HTML shrinks to a fraction of its size. The `Compress` package speaks **Deflate**, the method inside every `.gz` and `.zip` file and behind HTTP's `Content-Encoding: gzip`:

```rux
import Compress::{ Compress, CompressWriter, Decompress, DecompressReader, Format, Level };
```

This lesson compresses an 11,572-byte log to under 1,400 bytes, gets every byte back, and then does the same through a file, a piece at a time.

## Three containers

The compressed stream is the same in each; what differs is what is wrapped around it:

| `Format` | Wrapped in                                                  | Overhead | Where you meet it                  |
| -------- | ----------------------------------------------------------- | -------- | ---------------------------------- |
| `Raw`    | nothing: the bare Deflate stream                            | 0 bytes  | inside ZIP files                   |
| `Zlib`   | a 2-byte header and an Adler-32 checksum                    | 6 bytes  | PNG images, many network protocols |
| `Gzip`   | a 10-byte header, a CRC-32 checksum and the original length | 18 bytes | `.gz` files, HTTP                  |

The program's output shows exactly that: 1377 bytes raw, 6 more as zlib, 18 more as gzip. Whoever reads the data must be told the same format it was written in.

## Whole buffers

`Compress` takes the data as `byte[..]` and returns a `Vector<byte>` of the compressed bytes, allocated from the allocator you pass. `Decompress` takes them back:

```rux
let gzip = try Compress(allocator, data, Format::Gzip);
```

```rux
let unpacked = try Decompress(allocator, gzip.AsSlice(), Format::Gzip);
```

Both are declared `-> Vector<byte> throws IoError`, and `Main` is declared `throws IoError`, so plain `try` [passes](/docs/learn/propagate) any failure out of it. Both also take text directly, but what comes back is always bytes. So that the round trip compares bytes with bytes, the program views the log's characters as the bytes they are, once, with a [pointer slice](/docs/learn/pointer-slice) as the [Hash](/docs/learn/hash) lesson does:

```rux
func AsBytes(text: char8[..]) -> byte[..] {
    // Safety: `char8` and `byte` have the same size and alignment, so the `text.length` code units
    // at `text.data` are as many bytes, borrowed from the same storage as `text`.
    return unsafe { (text.data as *byte)[..text.length] };
}
```

Casting a pointer and indexing it are raw-pointer work the compiler cannot check, so they sit in an `unsafe` block, with a `// Safety:` comment saying why they are sound here.

## How hard to try

An optional fourth argument, a `Level`, says how hard the compressor looks for repeats. Higher levels find longer and more of them, and take longer to:

| `Level`   | Searches                      | The log, as gzip |
| --------- | ----------------------------- | ---------------- |
| `Store`   | not at all: data copied as is | 11595 bytes      |
| `Fastest` | takes the first match found   | 1771 bytes       |
| `Default` | a balance, close to zlib's    | 1395 bytes       |
| `Best`    | the most thorough             | 1360 bytes       |

`Store` is 23 bytes _larger_ than the log: the gzip header and trailer, plus a few bytes per stored block. The level is not written into the data, so `Decompress` never needs to know it. For a given level the output is always the same, which is why these sizes are the same on every run.

## What does not shrink

Compression only pays where something repeats. `Hello, Rux!` has nothing to repeat, so its 11 bytes come out as 31: the 18 bytes of gzip around a stream slightly longer than the text. Random bytes, and data that is already compressed, do not shrink either.

The checksum earns its place when something goes wrong. The program flips one bit in the middle of the compressed log, and `Decompress` throws an `IoError` of kind `InvalidInput` instead of returning something that is almost the log. The call sits in a [`try` block](/docs/learn/catch), whose `catch` arm checks the kind.

## Streams

`Compress` needs all the data in memory at once. For a file of any size, `CompressWriter` is a [`Writer`](/docs/learn/memory-stream) that compresses whatever is written to it into another writer — here a [file](/docs/learn/file):

```rux
var file = try File::Open(allocator, path, OpenOptions::Writing());
var writer = try CompressWriter(allocator, move file, Format::Gzip);
var written: uint = 0;
while written < text.length {
    let end = if written + 1000 < text.length { written + 1000 } else { text.length };
    written = try written + writer.Write(text[written..end]);
}
try writer.Finish();
```

```mermaid
flowchart LR
    w["`writer.Write`"] --> cw["`CompressWriter`"]
    cw -- "compressed blocks" --> f[("`access.log.gz`")]
    f --> dr["`DecompressReader`"]
    dr -- "`Read` into a buffer" --> r["the log, piece by piece"]
```

The writer _takes_ the file — a file is move-only, hence `move file` — and closes it when the writer is destroyed at the end of the function. Nothing is complete until `Finish` writes the last block and the checksum. `try` is written at the start of the whole assignment, `written = try written + writer.Write(…)`, because it may not stand to the right of the `+`.

`DecompressReader` is the matching `Reader`: each `Read` fills a buffer with decompressed data, and when there is no more, `Read` throws an `IoError` whose `IsEnd()` is `true` — only after the checksum has agreed. So the end of the data and a real failure arrive the same way, and a [guard](/docs/learn/guard) on the first `catch` arm tells them apart:

```rux
while true {
    let count = try reader.Read(buffer[..]) catch {
        error if error.IsEnd() => break,
        error => throw error
    };
    // … count the lines in buffer[..count]
}
```

The second arm passes any other error on with `throw`, out of `ReadLog` to `Main`.

## The program

The whole lesson is one package in the [Examples repository](https://github.com/rux-lang/Examples/tree/main/DataFormats/Compress). Its comments explain every step.

<!-- sync:program:start -->

```rux [Src/Main.rux]
// Compression finds what repeats in data and writes each repeat as a short reference back to an
// earlier copy. A log, a JSON document or a page of HTML repeats a great deal and shrinks to a
// fraction of its size; random bytes do not repeat and do not shrink at all.
//
// The Compress package speaks Deflate, the method inside gzip, zlib and ZIP files and behind
// HTTP's `Content-Encoding: gzip`. The same compressed data travels in one of three containers:
//
//     Format::Raw   the bare Deflate stream
//     Format::Zlib  a 2-byte header, the stream, and an Adler-32 checksum of the data
//     Format::Gzip  a 10-byte header, the stream, a CRC-32 checksum and the length: a .gz file
//
// `Compress` and `Decompress` work on data already in memory. `CompressWriter` and
// `DecompressReader` do the same through the `Writer` and `Reader` interfaces, a piece at a time,
// so a file of any size can be compressed without holding all of it at once.
//
// The file this program writes lives in its package's `Bin/` folder, and is deleted at the end.
import Allocator::{ Allocator, SystemAllocator };
import Collections::Vector;
import Compress::{ Compress, CompressWriter, Decompress, DecompressReader, Format, Level };
import FileSystem::{ DeleteFile, File, OpenOptions };
import Io::{ IoError, IoErrorKind, PrintLine };
import Path::{ OsString, Path };

// Text as the bytes it is made of, as in the Hash lesson. `Compress` and `Decompress` also take
// text directly, but what comes back is always bytes, so the log is viewed as bytes once and the
// round trip compares bytes with bytes.
func AsBytes(text: char8[..]) -> byte[..] {
    // Safety: `char8` and `byte` have the same size and alignment, so the `text.length` code units
    // at `text.data` are as many bytes, borrowed from the same storage as `text`.
    return unsafe { (text.data as *byte)[..text.length] };
}

func SameBytes(left: byte[..], right: byte[..]) -> bool {
    if left.length != right.length { return false; }
    for i in 0..left.length {
        if left[i] != right[i] { return false; }
    }
    return true;
}

// A web server's access log of `count` requests: a few paths and statuses in an order that looks
// random but is the same on every run, and a time in milliseconds. The order comes from a small
// random number generator whose arithmetic wraps on purpose, so it uses `*%` and `+%`.
func MakeLog(allocator: Allocator, count: int) -> Vector<char8> {
    let paths: char8[..][6] = ["/docs/learn/compress", "/docs/learn/url", "/images/logo.svg",
        "/v1/playground/run", "/blog", "/packages"];
    let statuses: char8[..][3] = [" 200 ", " 304 ", " 404 "];
    let digits = "0123456789";
    var log = Vector<char8>(allocator);
    var state: uint32 = 2026;
    for _ in 0..count {
        state = state *% 1664525 +% 1013904223;
        log.PushSlice("GET ");
        log.PushSlice(paths[((state >> 8) % 6) as uint]);
        log.PushSlice(statuses[((state >> 16) % 3) as uint]);
        log.Push(digits[((state >> 20) % 10) as uint]);
        log.Push(digits[((state >> 24) % 10) as uint]);
        log.PushSlice(" ms\n");
    }
    return move log;
}

// Writes `text` into a .gz file. The writer takes the file and compresses whatever is written
// to it, here 1000 characters at a time; nothing is complete until `Finish` writes the last block
// and the checksum. When the function returns the writer is destroyed, and the file it holds is
// closed. A file is move-only, so handing it over takes `move`:
//
//     CompressWriter(allocator, file, Format::Gzip)
//         error: cannot copy 'File', which owns resources
func WriteLog(allocator: Allocator, path: Path, text: char8[..]) throws IoError {
    var file = try File::Open(allocator, path, OpenOptions::Writing());
    var writer = try CompressWriter(allocator, move file, Format::Gzip);
    var written: uint = 0;
    while written < text.length {
        let end = if written + 1000 < text.length { written + 1000 } else { text.length };
        written = try written + writer.Write(text[written..end]);
    }
    try writer.Finish();
}

// Reads the .gz file back a buffer at a time, until the reader reports the end of the data. That
// end comes only after the checksum agreed.
func ReadLog(allocator: Allocator, path: Path) throws IoError {
    var file = try File::Open(allocator, path, OpenOptions::Reading());
    try PrintLine("file                {} bytes", file.Size());
    var reader = try DecompressReader(allocator, move file, Format::Gzip);
    var buffer: char8[1024];
    var total: uint = 0;
    var lines: uint = 0;
    while true {
        let count = try reader.Read(buffer[..]) catch {
            error if error.IsEnd() => break,
            error => throw error
        };
        for c in buffer[..count] {
            if c == '\n' { lines = lines + 1; }
        }
        total = total + count;
    }
    PrintLine("read back           {} bytes, {} lines", total, lines);
}

func Main() throws IoError {
    var system = SystemAllocator();
    let allocator: Allocator = system;

    let log = MakeLog(allocator, 400);
    let data = AsBytes(log.AsSlice());
    PrintLine("log                 {} bytes", data.length);

    // The same data in the three containers. The compressed stream inside is the same; the
    // containers differ only by the size of their header and checksum.
    let raw = try Compress(allocator, data, Format::Raw);
    let zlib = try Compress(allocator, data, Format::Zlib);
    let gzip = try Compress(allocator, data, Format::Gzip);
    PrintLine("raw                 {} bytes", raw.Length());
    PrintLine("zlib                {} bytes", zlib.Length());
    PrintLine("gzip                {} bytes", gzip.Length());

    // How hard to look for repeats. `Store` does not compress at all, so it comes out a little
    // larger than the data; the others trade time for size. `Default` is what `Compress` uses
    // when no level is given.
    let levels: Level[4] = [Level::Store, Level::Fastest, Level::Default, Level::Best];
    let names: char8[..][4] = ["store", "fastest", "default", "best"];
    for i in 0..4 {
        let packed = try Compress(allocator, data, Format::Gzip, levels[i]);
        PrintLine("gzip, {:<13} {} bytes", names[i], packed.Length());
    }

    // The round trip gives back every byte. Decompressing needs only the format: the level is
    // not part of the data.
    let unpacked = try Decompress(allocator, gzip.AsSlice(), Format::Gzip);
    PrintLine("round trip          {} bytes, identical: {}", unpacked.Length(),
        SameBytes(unpacked.AsSlice(), data));

    // Short text has nothing to repeat, and the container's header and checksum make it larger.
    let short = try Compress(allocator, "Hello, Rux!", Format::Gzip);
    PrintLine("11 bytes as gzip    {} bytes", short.Length());

    // The checksum catches damage. Change one bit of the compressed data and decompressing
    // fails with `InvalidInput` instead of returning wrong data.
    var damaged = Vector<byte>(allocator);
    damaged.PushSlice(gzip.AsSlice());
    damaged.AsMutableSlice()[100] = damaged.AsSlice()[100] ^ 0x01;
    try {
        Decompress(allocator, damaged.AsSlice(), Format::Gzip);
        PrintLine("damaged             accepted");
    } catch {
        error => PrintLine("damaged             refused, invalid input: {}",
            error.kind == IoErrorKind::InvalidInput)
    }

    // Streaming into a .gz file, and back out of it.
    var holder = OsString::FromText(allocator, "Bin/access.log.gz");
    let path = Path::FromView(holder.View());
    try WriteLog(allocator, path, log.AsSlice());
    try ReadLog(allocator, path);
    try DeleteFile(allocator, path);
}
```

## Common mistakes

::mistake
**Casting a pointer outside `unsafe`.**\
Leave the `unsafe` block off `AsBytes`, `return (text.data as *byte)[..text.length];`, and it fails with:

```text
error: casting '*char8' to '*uint8' requires 'unsafe'
help: wrap it in 'unsafe { ... }' and say why it holds in a '// Safety:' comment above it
```

followed by `error: indexing a raw pointer requires 'unsafe'`. The compiler cannot check either step, so say why they hold.
::

::mistake
**Forgetting `Finish`.**\
Without it, the log in this program never leaves the writer's buffer: the file is 0 bytes, and reading it back fails. A stream is complete only when `Finish` has written its last block and its checksum.
::

::mistake
**Handing over the file without `move`.**\
`CompressWriter(allocator, file, Format::Gzip)` fails with:

```text
error: cannot copy 'File', which owns resources
help: write 'move file' to transfer it, or 'file.Clone()' to copy it
```

The writer owns the file from then on; you no longer use `file` yourself.
::

::mistake
**Catching only the end.**\
A guarded arm covers only the errors its guard accepts. Leave out the `error => throw error` arm and the `catch` fails with:

```text
error: 'catch' arms do not cover every error of type 'IoError'
help: add a '_' arm, or bind the whole error, as in 'e => ...'
```

Decide what every other error does — here, pass it on.
::

## Try it yourself

1. Compress `gzip.AsSlice()` a second time. Does compressed data shrink again?
2. Decompress the gzip data cut short by three bytes, `gzip.AsSlice()[..gzip.Length() - 3]`. What happens?
3. Make the log ten times longer. How do the sizes at each level change?
4. Write the log as `Format::Zlib` in `WriteLog`, then read it with `Format::Gzip` in `ReadLog`, and see where it fails.
