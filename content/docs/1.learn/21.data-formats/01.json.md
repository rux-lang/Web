# JSON

::note
<!-- sync:needs:start -->

**You'll need**: [Allocator](/docs/learn/allocator), [Optional](/docs/learn/optional), [Catch](/docs/learn/catch), [String view](/docs/learn/string-view)
<!-- sync:needs:end -->

::

JSON is how programs that share nothing else — not a language, not a machine, not an owner — agree on what a value is. A web API answers in it, a browser stores settings in it, and a log line often is one. This lesson reads a JSON document with the `Json` package, takes typed values out of it, and shows how a broken document is refused.

```rux
import Allocator::{ Allocator, SystemAllocator };
import Json::{ JsonKind, JsonValue, Parse };
import Text::StringView;
```

## Parsing a document

`Parse` reads the whole text into a tree of values:

```
Parse(allocator, text) -> JsonValue throws JsonParseError
```

The tree needs memory — a document can be any size — so `Parse` takes an [allocator](/docs/learn/allocator) to get it from. `Main` makes the system allocator and hands out an `Allocator` view of it:

```rux
var system = SystemAllocator();
let allocator: Allocator = system;
```

`Parse` either returns the whole document, as its root value, or [throws](/docs/learn/fallible) the reason there is none. There is never half a document. The call sits in a [`try` block](/docs/learn/catch), so the rest of the block runs only when the parse succeeded, and the `catch` arm takes the reason when it did not:

```rux
try {
    let root = Parse(allocator, document);
    Inspect(root);
} catch {
    reason => PrintLine("refused at byte {}: {}", reason.Offset(), reason)
}
```

The document is one long string literal, with every `"` inside it escaped as `\"`:

```json
{ "name": "Rux", "year": 2026, "tags": ["fast", "small"], "flags": { "beta": true } }
```

## A tree of six kinds

Every value in the tree is one of six kinds, and `Kind()` says which. Containers hold more values, so the document above parses into this tree:

```mermaid
flowchart TD
    root["object"] -- "`name`" --> n["text: `Rux`"]
    root -- "`year`" --> y["number: `2026`"]
    root -- "`tags`" --> t["array"]
    root -- "`flags`" --> f["object"]
    t -- "`0`" --> t0["text: `fast`"]
    t -- "`1`" --> t1["text: `small`"]
    f -- "`beta`" --> b["boolean: `true`"]
```

Reading the tree always means asking a value what it is before taking it apart. Every question answers an [optional](/docs/learn/optional): `none` when the value is not what was asked for.

| Kind      | Ask with                     | Answers                                         |
| --------- | ---------------------------- | ----------------------------------------------- |
| `Object`  | `Find(name)`, `Length()`     | a reference to the member, `none` if missing    |
| `Array`   | `At(index)`, `Length()`      | a reference to the element, `none` past the end |
| `Text`    | `AsText()`                   | a `StringView`, `none` for any other kind       |
| `Number`  | `AsNumber()`, then `AsInt64` | `none` when the number is not that type         |
| `Boolean` | `AsBoolean()`                | `none` when the value is not a boolean          |
| `Null`    | `IsNull()`                   | `true` for `null`                               |

`Length()` is `none` for a value that is not a container, so the program writes `root.Length() ?? 0` to [fall back](/docs/learn/coalesce) to zero. `KindName` turns a kind into a word for printing, with the `_` arm covering the last one, `Null`.

## Finding a member

Member names are text, so `Find` takes a [`StringView`](/docs/learn/string-view). A small `Member` method makes one from a literal:

```rux
extend JsonValue {
    func Member(&self, name: char8[..]) -> &JsonValue? {
        return self.Find(StringView::FromValidated(name));
    }
}
```

`Find` answers a [reference](/docs/learn/reference) into the tree, or `none` when there is no such member. A reference that a function returns has to borrow from something, and a method's result borrows from its receiver — which is why `Member` is written in an [`extend`](/docs/learn/extension) block rather than as a free function.

Since the answer may be missing, the program tests it with [`is .Some(...)`](/docs/learn/presence) before reading it. Each test binds a name for the tests after it in the `&&` chain, and for the body, so one `if` both finds the member and checks that it is text:

```rux
if root.Member("name") is .Some(name) && name.AsText() is .Some(text) {
    PrintLine("name      {}", text);
}
PrintLine("license   present: {}", root.Member("license") is .Some(_));
```

The document has no `license`, and the program says so instead of crashing.

## Numbers keep their text

JSON has one kind of number, and it does not say how big or how precise a number may be. So a `JsonNumber` keeps the text it was written with, and converting it is a question that may be answered `none` — the text may have a fraction, or not fit the type asked for:

```rux
if root.Member("year") is .Some(member) && member.AsNumber() is .Some(number) {
    let year = number.AsInt64();
    PrintLine("year      {} (text \"{}\", fits an int64: {})", year ?? 0, number.Text(),
        year is .Some(_));
}
```

`AsNumber` answers the number, or `none` if the value were some other kind, and `AsInt64` answers the `int64`, or `none` if the text does not fit one.

## Arrays and nested objects

An array is walked by index, and each element is asked its kind like any other value. A nested object is just another value with members of its own:

```rux
if root.Member("tags") is .Some(tags) {
    for i in 0..(tags.Length() ?? 0) {
        if tags.At(i) is .Some(tag) && tag.AsText() is .Some(text) {
            PrintLine("tags[{}]   {} {}", i, KindName(tag.Kind()), text);
        }
    }
}

if root.Member("flags") is .Some(flags) && flags.Member("beta") is .Some(beta) {
    let value = beta.AsBoolean();
    PrintLine("beta      boolean: {}, value: {}", value is .Some(_), value ?? false);
}
```

Every member is checked, even though the document is a literal in the program and they are known to be there. The types leave no other way to read them: an optional has to be unwrapped before its value can be used, so a document from outside cannot crash the program with a member it lacks.

## Malformed input

JSON is strict, and `Parse` refuses anything that is not exactly JSON. The error says why, and at which byte the parser stopped. `Check` parses each document in a `try` block of its own and prints what happened:

| Document          | Refused at | Because                                   |
| ----------------- | ---------- | ----------------------------------------- |
| `[1, 2, 3,]`      | byte 9     | a trailing comma: `]` cannot follow `,`   |
| `{'name': 'Rux'}` | byte 1     | single quotes begin no token in JSON      |
| `{"open": [1, 2}` | byte 14    | `}` cannot close an array                 |
| `{"a": 1} extra`  | byte 9     | text after the end of the document        |
| _(empty)_         | byte 0     | the document ended before any value began |

Offsets count from zero, so byte 9 is the tenth. A message that names the byte lets a person go straight to the mistake.

## The program

The whole lesson is one package in the [Examples repository](https://github.com/rux-lang/Examples/tree/main/DataFormats/Json). Its comments explain every step.

<!-- sync:program:start -->

```rux [Src/Main.rux]
// JSON is how programs that share nothing else agree on what a value is. The Json package reads
// a document into a tree of `JsonValue`s, and every value in the tree is one of six kinds: text,
// number, boolean, null, array or object.
//
//     Parse(allocator, text) -> JsonValue throws JsonParseError
//
// Parsing hands back a whole document or throws the reason there is none, never half of one.
// Reading the tree then means asking a value what it is before taking it apart: `Find` and `At`
// answer `none` when the member or element is not there, and the conversions answer `none` when
// the value is some other kind.
import Allocator::{ Allocator, SystemAllocator };
import Io::PrintLine;
import Json::{ JsonKind, JsonValue, Parse };
import Text::StringView;

func KindName(kind: JsonKind) -> char8[..] {
    return match kind {
        JsonKind::Text => "text",
        JsonKind::Number => "number",
        JsonKind::Boolean => "boolean",
        JsonKind::Array => "array",
        JsonKind::Object => "object",
        _ => "null"
    };
}

// Member names are compared as text, so `Find` takes a `StringView`. The answer borrows from the
// value it was found in, so it is an optional reference, and the helper is a method: a reference
// result borrows from the receiver.
extend JsonValue {
    func Member(&self, name: char8[..]) -> &JsonValue? {
        return self.Find(StringView::FromValidated(name));
    }
}

func Inspect(root: &JsonValue) {
    PrintLine("root      {} of {} members", KindName(root.Kind()), root.Length() ?? 0);

    // A member that is not there is `none`, so check before reading it. Each `is` test binds a
    // name for the tests after it in the `&&` chain, and for the body.
    if root.Member("name") is .Some(name) && name.AsText() is .Some(text) {
        PrintLine("name      {}", text);
    }
    PrintLine("license   present: {}", root.Member("license") is .Some(_));

    // A number keeps the text it was written with, and converting it is a question that can
    // be answered `none`: the text may have a fraction, or not fit the type asked for.
    if root.Member("year") is .Some(member) && member.AsNumber() is .Some(number) {
        let year = number.AsInt64();
        PrintLine("year      {} (text \"{}\", fits an int64: {})", year ?? 0, number.Text(),
            year is .Some(_));
    }

    // An array is walked by index, and each element is asked its kind like any other value.
    if root.Member("tags") is .Some(tags) {
        for i in 0..(tags.Length() ?? 0) {
            if tags.At(i) is .Some(tag) && tag.AsText() is .Some(text) {
                PrintLine("tags[{}]   {} {}", i, KindName(tag.Kind()), text);
            }
        }
    }

    // A nested object is just another value with members of its own.
    if root.Member("flags") is .Some(flags) && flags.Member("beta") is .Some(beta) {
        let value = beta.AsBoolean();
        PrintLine("beta      boolean: {}, value: {}", value is .Some(_), value ?? false);
    }
}

// `Parse` throws, so the parse sits in a `try` block, and the `catch` arm takes the reason.
func Check(allocator: Allocator, document: char8[..]) {
    try {
        let root = Parse(allocator, document);
        PrintLine("{:18} parsed as {}", document, KindName(root.Kind()));
    } catch {
        reason => PrintLine("{:18} refused at byte {}: {}", document, reason.Offset(), reason)
    }
}

func Main() -> int {
    var system = SystemAllocator();
    let allocator: Allocator = system;

    let document =
        "{\"name\":\"Rux\",\"year\":2026,\"tags\":[\"fast\",\"small\"],\"flags\":{\"beta\":true}}";
    try {
        let root = Parse(allocator, document);
        Inspect(root);
    } catch {
        reason => PrintLine("refused at byte {}: {}", reason.Offset(), reason)
    }

    // Malformed input. The failure says why, and the byte where the parser stopped, so a message
    // to a person can point at the problem. JSON is strict: no trailing commas, no single quotes.
    PrintLine("");
    Check(allocator, "[1, 2, 3]");
    Check(allocator, "[1, 2, 3,]");
    Check(allocator, "{'name': 'Rux'}");
    Check(allocator, "{\"open\": [1, 2}");
    Check(allocator, "{\"a\": 1} extra");
    Check(allocator, "");
    return 0;
}
```

Besides `Io`, its `Rux.toml` lists `Allocator`, `Json` and `Text` under `[Dependencies]`.

## Common mistakes

::mistake
**Looking up a member with a plain literal.**\
`Find` compares names as text, and takes a `StringView`. `self.Find(name)` with a `char8[..]` fails with:

```text
error: argument 1 to 'Find' has type 'char8[..]', but parameter 'name' requires 'StringView'
```

Wrap it: `StringView::FromValidated(name)`.
::

::mistake
**Using a member before checking it is there.**\
`Member` answers `&JsonValue?`, not a value. `let name = root.Member("name");` followed by `name.AsText()` fails with:

```text
error: type '&JsonValue?' has no field 'AsText'
```

Unwrap it first — with `if root.Member("name") is .Some(name)`, a `match`, or `??`.
::

::mistake
**Parsing without `try`.**\
`Parse` can throw, and every call that can throw must be marked. `let root = Parse(allocator, document);` on its own fails with:

```text
error: call to 'Parse' can throw 'JsonParseError' but is not marked with 'try'
help: write 'try' before the expression
```

Put it in a `try` block with a `catch`, as `Main` and `Check` do.
::

::mistake
**Forgetting the allocator.**\
`Parse(document)` fails with:

```text
error: call to 'Parse' expects 2 arguments, but 1 was provided
```

The tree's memory has to come from somewhere, and the allocator says where.
::

## Try it yourself

1. Add `"license": null` to the document. Check it with `IsNull()`.
2. Add `"version": 1.5`. What do `AsInt64` and `AsFloat64` each answer for it?
3. Pass `{"a": 1, "a": 2}` to `Check`. JSON does not forbid a repeated name — but what does this parser do with one?
4. List every member of the root object with `MemberAt(i)`, printing each one's `name` and the kind of its `value`.
